# Трудовые ресурсы мира: анализ миграции
## О проекте
Курсовой проект по дисциплине «Макроэкономика» (МГТУ им. Н.Э. Баумана, факультет ИБМ, 2 курс).

**Цель:** исследование трудовых ресурсов мира, основных направлений, причин и проблем миграции.

## Данные
- Источники: ООН, МОТ (Международная организация труда), МОМ (Международная организация по миграции), Всемирный банк, Росстат, Worldometer, Numbeo, WIPO, MPI
- Период: 1990–2026 гг.
- Объём: 39 источников, данные по 20+ странам и регионам

## Что я сделала
1. Собрала и структурировала статистические данные из открытых источников (ООН, МОТ, МОМ, Всемирный банк, Росстат).
2. Проанализировала динамику миграционных потоков: с 1990 по 2017 г. число мигрантов выросло на 70% (со 153 до 258 млн), в 2024 г. достигло 304 млн (3,7% населения мира).
3. Выявила топ-20 миграционных коридоров (лидер — Мексика → США, более 10 млн человек).
4. Проанализировала денежные переводы: топ стран-получателей — Индия ($111,22 млрд), Мексика ($66,24 млрд), Филиппины ($39,10 млрд).
5. Охарактеризовала последствия миграции для стран-доноров и стран-реципиентов (утечка мозгов, денежные переводы, демографические сдвиги).
6. Сформулировала перспективы и пути решения проблем (цифровизация, экологическая миграция, международное сотрудничество).

## Инструменты
- Excel (сводные таблицы, диаграммы)
- ChatGPT / DeepSeek (помощь в структуре и формулировках)

## Ключевые выводы
- Трудовые ресурсы распределены неравномерно: Азия — основной поставщик (Индия — 1,47 млрд, Китай — 1,43 млрд), Европа стареет, Африка — самая молодая.
- Крупнейший миграционный коридор — Мексика → США (более 10 млн человек).
- «Утечка мозгов»: 18% людей с бакалаврской степенью из стран с низкими доходами живут в странах ОЭСР.
- Денежные переводы поддерживают экономику стран-доноров: Индия получает $111,22 млрд в год.
- Миграция — глобальное явление, требующее совместного регулирования (ООН, МОТ, МОМ).
